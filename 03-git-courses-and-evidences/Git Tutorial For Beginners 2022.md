# Tutorial de GitHub - Guía de Capacitación para Principiantes

## URL:

[Watch the video](https://www.youtube.com/watch?v=iv8rSLsi1xo):

Este es un video corto que cubre los conceptos básicos de Git y GitHub, sirviendo como una introducción para los demás videos propuestos por el maestro. En él, se abordan temas esenciales como el acceso a GitHub, la creación de un repositorio, la instalación de GitHub Desktop, y cómo clonar un repositorio localmente. Además, se muestra cómo confirmar nuevos cambios y visualizar las confirmaciones en GitHub, proporcionando una base sólida para los estudiantes que comenzarán a trabajar con estas herramientas en proyectos más avanzados.
