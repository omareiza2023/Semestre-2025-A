## Puntos Claves sobre el Módulo  

1. El explorador interpreta el marcado HTML y lo presenta utilizando estilos y formatos legibles por las personas al representar un documento HTML.  

2. El marcado es texto de encapsulado con indicadores que son una guía de lo que se debe hacer con ese texto.  

3. Los marcados se basan en el texto e incluyen enlaces a recursos, por lo que son más fáciles de interpretar y visualizar.  

4. Un documento HTML correctamente estructurado incluye la etiqueta HTML, la sección head y la sección body.  

5. Los atributos HTML son datos adicionales que una etiqueta puede necesitar para proporcionar al analizador información suficiente para crear el formateo que necesita el elemento.  

6. Una etiqueta semántica describe con claridad su función al explorador y al desarrollador web.  

7. Los marcos son herramientas que utilizan en gran medida un lenguaje de script como JavaScript para manejar los datos.  

8. Los desarrolladores crearon el lenguaje de hojas de estilo en cascada (CSS) para añadir estilo a elementos de la misma clase o id sin necesidad de aplicar estilo a cada elemento en un documento HTML.  

9. Un estilo en una hoja de estilo tiene tres partes básicas: un selector, un nombre de nodo y un bloque de declaración. El bloque de declaración tiene uno o varios estilos que se componen de propiedades y valores.  

10. Una de las principales características de CSS es que los elementos hijo heredan el estilo de los elementos padre a menos que este estilo se sustituya.  

11. CSS se centra en gran medida en la presentación del sitio web, y el código puede programar el texto, el estilo y la función del sitio.  

12. JavaScript controla la interactividad en un sitio web, como pulsar en un botón, las ventanas emergentes y actualizar una página web.  

13. JavaScript, HTML y CSS se combinan en el código para visualizar una página web y todas sus características.  

14. El método en cascada es un plan de acciones paso a paso que fluye hacia abajo como una cascada.  

15. El enfoque ágil es iterativo, lo que significa que el proceso se puede repetir a menudo y en ocasiones los mismos pasos se pueden repetir varias veces.  

16. Scrum es un enfoque iterativo de la implementación de la metodología ágil en el que los equipos entregan trabajo en sprints y participan en ceremonias Scrum.
