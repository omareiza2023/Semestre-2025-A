# Desarrollar una página web de lista de tareas interactiva

Este módulo está enfocado en aplicar conocimientos de codificación, diseño y pruebas en el desarrollo web. El objetivo es crear una página web interactiva que permita a los empleados realizar un seguimiento de sus tareas laborales, utilizando herramientas y tecnologías web comunes.

## Puntos Claves sobre el Módulo  

1. El desarrollo web requiere la aplicación de conocimientos de codificación, diseño y realización de pruebas.  

2. La finalidad de la página web es ayudar a los empleados de la empresa a realizar un seguimiento de sus tareas de trabajo en una lista de tareas interactiva.  

3. En su escenario, ha revisado los requisitos del gestor de producto y un diagrama de wireframes del diseñador web como ayuda para definir su desarrollo web.  

4. Ha tenido la oportunidad de hacer prácticas en simulaciones para:  
    - Utilizar VS Code como IDE para instalar una extensión y configurar archivos HTML, CSS y JavaScript vacíos para un nuevo proyecto.  
    - Escribir HTML para crear la estructura y los elementos individuales de una página web.  
    - Crear estilos usando CSS para que una página web resulte atractiva.  
    - Escribir código JavaScript para añadir interactividad y diseñar los elementos de una página web.  
    - Probar una página web para garantizar su correcto funcionamiento.
