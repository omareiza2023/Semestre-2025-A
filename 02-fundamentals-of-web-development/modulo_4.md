## Puntos Claves sobre el Módulo  

1. JavaScript es un lenguaje de programación ampliamente utilizado para desarrollo web front-end y back-end.  

2. Los desarrolladores web utilizan JavaScript para crear sitios web dinámicos y responder a sucesos iniciados por los usuarios.  

3. JavaScript exhibe características de la programación funcional y de la programación orientada a objetos.  

4. Los objetos tienen miembros, como constantes, propiedades, métodos y sucesos.  

5. La programación orientada a objetos permite la reutilización de código, la herencia y la encapsulación.  

6. JavaScript utiliza variables para contener datos o funciones.  

7. Distintos lenguajes admiten distintos tipos de datos, pero todos tienen un conjunto de tipos primitivos a partir de los cuales se derivan otros.  

8. Las variables JavaScript pueden contener cualquier tipo de datos, y JavaScript es capaz de decidir de qué tipo de datos se trata durante la ejecución del programa.  

9. Los datos booleanos pueden tener valores de verdadero o falso, los datos de números son los datos que incluyen valores numéricos, los datos de cadena son los datos textuales, los datos sin definir son una variable que no tiene ningún valor, y los datos Null solo tienen el valor Null.  

10. Las bases de datos almacenan los datos en tablas, que se componen de registros.  

11. Las cuatro operaciones principales de base de datos son crear, leer, actualizar y suprimir (CRUD, por sus siglas en inglés).  

12. SQL es el lenguaje que los desarrolladores utilizan para gestionar las bases de datos y realizar operaciones de datos.  

13. Node.js es un servidor web de código abierto, sin bloqueo, basado en JavaScript.  

14. NPM permite a los desarrolladores ampliar Node.js y otras herramientas utilizando bibliotecas y marcos de código abierto.
