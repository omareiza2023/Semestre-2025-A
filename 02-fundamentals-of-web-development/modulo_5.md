# Prueba y despliegue de sitios web

Este módulo aborda las técnicas y herramientas necesarias para probar y desplegar sitios web, asegurando su rendimiento, funcionalidad y accesibilidad. En el desarrollo web, las pruebas son cruciales para identificar defectos y mejorar la experiencia del usuario. El despliegue continuo y el uso de sistemas de control de versiones también son esenciales para entregar actualizaciones periódicas a los usuarios.

## Puntos Claves sobre el Módulo  

1. Los desarrolladores web prueban los sitios web en busca de defectos relacionados con la experiencia del usuario y el software.  

2. Existen muchos tipos distintos de pruebas web con objetivos y estrategias específicos, entre otros, la aceptación, la integración, el rendimiento y la usabilidad.  

3. Los desarrolladores web deben considerar la interfaz de usuario, el diseño reactivo, el código, las API y las bases de datos al probar un sitio web.  

4. Los desarrolladores web también utilizan el control de versiones para el seguimiento y la gestión de los cambios del código de software.  

5. Un sistema de control de versiones puede incluir características como un repositorio de código, herramientas de colaboración y despliegue de código.  

6. Los desarrolladores web utilizan el método de entrega continua para entregar actualizaciones a los sitios web para que estos puedan probarse automáticamente. Utilizan un método de despliegue continuo para entregar periódicamente las nuevas compilaciones a los usuarios.  

7. DevOps es un método de despliegue que promueve una colaboración más estrecha entre la empresa que utiliza el sitio web, el equipo de desarrollo del sitio web y el equipo de operaciones de tecnologías de la información (TI).  

8. El ciclo de vida de DevOps consta de seis flujos de trabajo generales con los que los desarrolladores web pueden publicar más rápido sitios web de alta calidad.  

9. Los exploradores web se comunican con los servidores mediante el protocolo de transferencia de hipertexto (HTTP), que facilita las solicitudes de carga de páginas web mediante enlaces de hipertexto.  

10. El diseño de un sitio web es reactivo cuando adapta su aspecto al factor de forma en el que se visualiza.  

11. Los marcos son paquetes de software que incluyen código que se integra en un sitio web y ayudan a los desarrolladores web a desarrollar un sitio reactivo. Los marcos también proporcionan bibliotecas de código que pueden manejar la gestión de datos, controlar la interfaz de usuario y manejar tareas comunes como la creación y entrega de formularios.  

12. Los desarrolladores web utilizan un wrapper de aplicaciones para entregar sitios web como aplicaciones descargables a través de una tienda de aplicaciones o desde un sitio web.  

13. Para automatizar el proceso de despliegue, los desarrolladores web pueden utilizar interfaces de línea de mandatos, la integración de código, herramientas de programación, planos y herramientas basadas en la nube.  

14. La nube ha revolucionado el desarrollo web proporcionando servicios como el alojamiento, la réplica, la escalabilidad, la seguridad, la supervisión y herramientas de desarrollo.  

15. Un contenedor de software es un paquete estandarizado de software que contiene todo lo que se necesita para ejecutar un programa.
