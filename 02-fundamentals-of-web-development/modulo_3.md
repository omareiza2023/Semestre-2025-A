## Puntos Claves sobre el Módulo  

1. Las etiquetas se componen de corchetes de apertura y de cierre con un nombre de etiqueta en el medio. Los elementos son pares de etiquetas que encapsulan o envuelven otros elementos o contenido web.  

2. HTML es un lenguaje declarativo, lo que significa que describe las reglas de lo que debe visualizar una página y cuál debe ser su comportamiento, pero no cómo un explorador debe implementar esas reglas.  

3. El anidamiento se produce cuando los desarrolladores incluyen elementos HTML entre otros elementos HTML.  

4. Un elemento HTML que contiene otro es el padre de ese elemento. Los elementos HTML dentro del padre son los elementos hijo.  

5. Los documentos HTML deben incluir los elementos `<html> </html>`, `<head></head>` y `<body></body>`.  

6. Los atributos pueden cambiar el estilo del elemento, establecer una propiedad e incluir metadatos para que los utilice un programa de script.  

7. Organizar el código y el contenido en la página facilita la exploración y la navegación del código, lo que hace que la colaboración sea más fluida.  

8. Las buenas prácticas para ayudar a los desarrolladores web a mantenerse organizados son los comentarios, las convenciones de estilo, los elementos semánticos y la organización de la sección de cabecera en un documento HTML.  

9. CSS es una colección de estilos que un desarrollador web utiliza para añadir diseño a las páginas web.  

10. En HTML, los elementos hijo pueden heredar los estilos de los elementos padre.  

11. Las hojas de estilo externas son estilos que se ponen en un archivo separado con una extensión `.css`.  

12. Un estilo en una hoja de estilo tiene tres partes básicas: un selector, un nombre de nodo y un bloque de declaración.  

13. Un bloque de declaración tiene una o varias declaraciones de estilo que constan de propiedades y valores.  

14. Para añadir un estilo a un elemento HTML, los desarrolladores web utilizan el selector de clase, el selector de id, el selector de elemento o el estilo en línea en el elemento al que se va a aplicar estilo.  

15. El modelo de cuadro CSS es un método para diseñar un sitio web utilizando CSS.  

16. Los cuadros CSS tienen cinco componentes principales: altura, anchura, márgenes, relleno y borde. Cada uno de estos tiene atributos que proporcionan al desarrollador web un control preciso sobre cómo se comporta el cuadro en distintos escenarios.  

17. Los desarrolladores web siguen las buenas prácticas de establecer las declaraciones doctype para cada documento HTML, utilizar hojas de estilo, utilizar etiquetas de cierre que ayudan al explorador a definir el ámbito del contenido y guardar y revisar su trabajo con frecuencia.  

18. Los IDE son software con una interfaz de usuario central que incluye todas las herramientas que necesita un desarrollador web. Los IDE simplifican el flujo de trabajo de un desarrollador.  

19. Las características del IDE incluyen un editor de código, compilación inteligente del código, autoguardado y depurador integrado.
